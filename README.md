# Bloom — ラフテル キャスト顧客管理・店舗連携システム

キャストが自分の顧客情報・来店・接客メモをスマホで管理し、必要な情報だけを担当黒服・責任者と共有するための業務支援システム。

## 技術スタック
- Laravel 12 / PHP 8.2+（開発環境は 8.5）
- MySQL 8+（開発はローカル、本番は AWS RDS 予定）
- Blade（レスポンシブ・スマホ最優先）
- タイムゾーン：Asia/Tokyo（JST 統一）／文字コード：UTF-8

## セットアップ（ローカル）
```bash
cp .env.example .env
# .env の DB_DATABASE / DB_USERNAME / DB_PASSWORD を設定
php artisan key:generate
php artisan migrate
php artisan db:seed          # 初期ロール・店舗(ラフテル)・サンプルアカウント
php artisan serve
```

### 開発用シードアカウント（パスワードはすべて `password`）
| ログインID | 役割 |
|---|---|
| `admin` | システム管理者 |
| `tencho` | 責任者・店長 |
| `kurofuku1` | 担当黒服 |
| `yui` / `rin` | キャスト |

※ 本番では初回パスワードは自動発行＋初回ログイン時に本人が変更（`must_change_password`）。

## ロールと権限（要点）
- **キャスト**：自分の顧客・メモ・来店のみ。他キャストの情報は見えない。
- **担当黒服**：担当キャストが共有を許可した情報のみ（自分用メモは見えない）。
- **責任者・店長**：店舗全体・キャスト別の集計、アカウント作成/停止、担当紐付け。個人メモは原則不可。
- **システム管理者**：全体管理。「自分用メモ」は通常不可、安全管理時のみ理由記録付きで閲覧（§3-1）。

全クエリは `store_id` スコープを強制（`App\Models\Concerns\BelongsToStore`）。認可はサーバー側で実施（`role` ミドルウェア）。

## セキュリティ方針
HTTPS 必須・RBAC・店舗単位分離・監査ログ・退店者の即時停止・秘密情報は環境変数/Secrets Manager。個人情報は接客に必要な範囲に最小化（マイナンバー・カード番号・LINE会話全文等は収集しない）。
